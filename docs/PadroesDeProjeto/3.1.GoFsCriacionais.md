# 3.1. Módulo Padrões de Projeto GoFs Criacionais

## Visão Geral
Os padrões criacionais fornecem mecanismos de criação de objetos que aumentam a flexibilidade e a reutilização de código existente. No **ConhecendoIA**, utilizamos esses padrões para gerenciar instâncias únicas de conexão, montar estruturas complexas de trilhas de aprendizagem e instanciar notificações de forma dinâmica e escalável.

## Padrões Implementados

| Padrão | Contexto de Aplicação no ConhecendoIA | Documentação Completa |
|--------|---------------------------------------|-----------------------|
| **Factory Method** | Criação dinâmica de notificações (fórum, conquistas, avisos) delegando a instanciação para as subclasses corretas. | [Acessar 3.1.1 Factory Method](3.1.1Factory.md) |
| **Builder** | Construção passo a passo de Trilhas de Aprendizagem, configurando diferentes módulos educacionais e níveis de dificuldade de forma fluente. | [Acessar 3.1.2 Builder](3.1.2Builder.md) |
| **Singleton** | Garantia de uma instância única para o Gerenciador de Conexão com o Banco de Dados, protegendo contra sobrecarga de conexões. | [Acessar 3.1.3 Singleton](3.1.3Singleton.md) |
