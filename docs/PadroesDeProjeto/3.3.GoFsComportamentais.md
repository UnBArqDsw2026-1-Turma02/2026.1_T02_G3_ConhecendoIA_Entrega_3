# 3.3. Módulo Padrões de Projeto GoFs Comportamentais

## Visão Geral
Os padrões comportamentais lidam com algoritmos e a atribuição de responsabilidades entre os objetos, definindo formas elegantes de comunicação e de fluxo de controle. No ecossistema do **ConhecendoIA**, nós os aplicamos para gerenciar as permissões dinâmicas de sessão, permitir reatividade nas curtidas do fórum e customizar estratégias de ordenação visual.

## Padrões Implementados

| Padrão | Contexto de Aplicação no ConhecendoIA | Documentação Completa |
|--------|---------------------------------------|-----------------------|
| **Strategy** | Comportamentos de ordenação da lista de postagens (mais recentes, mais antigos, A-Z), permitindo a troca do algoritmo em tempo de execução. | [Acessar 3.3.1 Strategy](3.3.1Strategy.md) |
| **Observer** | Sistema de mensageria onde Serviços de Email e Push se inscrevem para reagir a comentários e interações em postagens acadêmicas. | [Acessar 3.3.2 Observer](3.3.2Observer.md) |
| **State** | Controle de nível hierárquico da sessão do usuário (Visitante, Membro, Moderador, Admin) transitando de forma orgânica os privilégios na interface. | [Acessar 3.3.3 State](3.3.3State.md) |
