# 3.2. Módulo Padrões de Projeto GoFs Estruturais

## Visão Geral
Os padrões estruturais explicam como montar objetos e classes em estruturas maiores, mantendo-as flexíveis e eficientes. No projeto **ConhecendoIA**, aplicamos os padrões estruturais para blindar camadas de segurança, adicionar funcionalidades dinâmicas durante a execução de scripts e otimizar processos na arquitetura.

## Padrões Implementados

| Padrão | Contexto de Aplicação no ConhecendoIA | Documentação Completa |
|--------|---------------------------------------|-----------------------|
| **Proxy** | Implementação de proxies para lidar com controle de permissão e proteção em métodos críticos, bem como realizar *caching* estrutural. | [Acessar 3.2.1 Proxy](3.2.1Proxy.md) |
| **Decorator** | Adição de responsabilidades dinâmicas ao Executor de Códigos Python (IDE), anexando funcionalidades independentes de métricas e Sandbox de segurança. | [Acessar 3.2.2 Decorator](3.2.2Decorator.md) |
