# 3. Desenho de Software (Padrões de Projeto)

Bem-vindo ao módulo de Desenho de Software do projeto **ConhecendoIA**. Nesta etapa, a equipe documentou e implementou diversas soluções arquiteturais baseadas no catálogo clássico da *Gang of Four* (GoF) para resolver problemas recorrentes no desenvolvimento da nossa plataforma de ensino.

A adoção dos padrões de projeto foi essencial para garantir a manutenibilidade, escalabilidade e a separação de responsabilidades (Single Responsibility Principle) dentro dos ecossistemas do Fórum e da IDE de código.

Nesta seção, você encontrará o detalhamento dos padrões escolhidos, divididos nas três categorias principais:

* [3.1. Padrões de Projeto GoFs Criacionais](3.1.GoFsCriacionais.md)
* [3.2. Padrões de Projeto GoFs Estruturais](3.2.GoFsEstruturais.md)
* [3.3. Padrões de Projeto GoFs Comportamentais](3.3.GoFsComportamentais.md)

Além dos artefatos técnicos, também registramos a metodologia de trabalho da equipe:

* [3.4. Participações - Padrões de Projeto](3.4.ParticipacoesPadroes.md)
* [3.5. Iniciativas Extras - Padrões de Projeto](3.5.IniciativasExtras.md)

**Metodologia de Estudo e Implementação:**
A equipe utilizou sessões assíncronas de estudo (através de referências consagradas como *Refactoring Guru* e *Head First Design Patterns*) e discussões síncronas para alinhar quais padrões se encaixariam melhor nas dores reais do projeto. Cada padrão escolhido não apenas foi modelado com diagramas UML, mas ativamente desenvolvido na base de código Frontend ou simulado em rotinas lógicas essenciais para a plataforma.
